### Frontend
| Technology | Purpose |

| Technology | Purpose |
|------------|---------|
| **MongoDB** | Database |
| **Mongoose** | ODM |
| **NextAuth.js v5** | Authentication (credentials + OAuth) |
| **Socket.io** | Real-time messaging |
